About this project

Built while learning DNS, Linux, and agentic engineering

Domain Toolkit is a personal project — a place to practice DNS, networking, and full-stack development end to end.

Domain Toolkit was built by Okoh Onyedikachi David as a hands-on way to learn how DNS actually works — records, propagation, WHOIS, and domain health — rather than just reading about it.

Every lookup on this site runs against real public DNS-over-HTTPS APIs and a small serverless WHOIS function — nothing here is faked or hardcoded sample data.
