What is DNS?

DNS (Domain Name System) is the internet's phone book. It translates human-readable domain names (like example.com) into IP addresses (like 93.184.216.34) that computers use to identify each other.

Key Points

  • DNS is a distributed system.
  • It is hierarchical and redundant.
  • DNS records store information about domain names.
  • Propagation can take time when records change.

Record types explained

DNS Record Types

A, AAAA, CNAME, MX, TXT and more, and what each one is for.

A Record

Maps a domain to an IPv4 address.

AAAA Record

Maps a domain to an IPv6 address.

CNAME Record

Points a domain to another domain name.

MX Record

Directs email to the correct mail server.

TXT Record

Stores text data, often used for verification.

NS Record

Lists the authoritative name servers for a domain.

SOA Record

Holds administrative info about the DNS zone.

SPF, DKIM & DMARC

Email authentication records that reduce spoofing.

Domain & WHOIS

Registration data: owner, registrar, and key dates.

SSL Certificates

Encrypts traffic between browsers and your server.
